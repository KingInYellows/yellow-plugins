# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/KingInYellows/yellow-plugins/security/advisories/new).
Do not open a public issue for a vulnerability.

Include the affected plugin and version, the steps to reproduce, and the impact
you expect. You should get a first reply within a week. This is a one-maintainer
project, so fixes ship on a best-effort basis.

## Scope

In scope: the plugins under `plugins/`, their hooks and shell scripts, the
marketplace manifests, and the validation tooling in this repository.

Out of scope: Claude Code itself (report those to Anthropic), and third-party
MCP servers or CLIs that a plugin installs or calls.

## Supported versions

Only the latest released version of each plugin receives fixes.
