---
title: Write prompts for the current Claude models
applies_when:
  - An agent, command or skill body is added or rewritten
  - A prompt gains rule lists, emphasis or verification instructions
tags: [prompting, style, agents, skills]
---

Write brief imperative sentences that carry the project facts Claude cannot
infer. Avoid ALL-CAPS rule lists, "be thorough" exhortations and
self-verification loops; the current Claude models follow plain instructions
closely, and emphasis makes them over-apply a rule.

Name model generations version-free ("the current Claude models"), so the text
does not go stale at the next release.
