# yellow-plugins rule pack

Team rules for this repository's plugin Markdown (agents, commands, skills) that
need judgment to apply. Rules a validator can check belong in a validator
instead.

`/review:pr` gives these rules to `project-standards-reviewer`, read from the
PR's base branch. `/flow:plan` searches them alongside `docs/solutions/`. The
format is in [docs/rule-packs.md](../../docs/rule-packs.md).
