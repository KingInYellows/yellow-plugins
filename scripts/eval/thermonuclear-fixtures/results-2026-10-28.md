README in the same PR:

  Drop the `--`.
- The smoke accepts only Codex CLI 0.157.0 (`CLI_VERSION` in

  0.163.0 (Windows), both rejected, so 0.157.0 was installed into a scratch

After a window reload, Cursor's plugin log recorded
`loadUserLocalPlugin yellow-review loaded` with no errors, but the requester did
not see `yellow-thermonuclear-review` among their skills. The same log showed
Cursor also importing an older `yellow-review@yellow-plugins` 3.2.1 from the
requester's Claude Code install, and the Customize page lists a Cursor "Yellow
Plugins" marketplace snapshot from 2026-02-18. Cursor does not log which
same-named plugin wins, and its docs say a marketplace install takes precedence
over a local copy, so the likely cause is a name collision, not a defect in the
generated plugin. This was not confirmed, and the in-editor invocation was not
run.
