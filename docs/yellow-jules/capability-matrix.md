## Evidence labels

Defined once here; every row below carries exactly one.

| Label                    | Meaning                                                                                                                                                              |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `documented`             | Stated in the package readme (`README.md` in the 0.2.0 tarball) or vendor docs. Not verified against code.                                                           |
| `source-inspected`       | Read from the packed `dist/types.d.ts` (`T<line>`) or `dist/index.mjs` (`M<line>`). Not executed.                                                                    |
| `packed-artifact-tested` | Exercised on the packed 0.2.0 artifact against the loopback fake server in sdk-investigation.md; request bodies, counts, load, side effects.                         |
| `live-observed`          | Observed against the real Jules API. **No row carries this label in PR1**: the investigation was zero-spend, and the first live evidence is the R53 smoke after PR3. |

Response shapes returned by the fake server are illustrative and never raise a
row above `source-inspected`; only request bodies, request counts, module
loading, and filesystem side effects reach `packed-artifact-tested`
(`docs/solutions/code-quality/golden-fixture-parity-vs-contract-correctness.md`).
